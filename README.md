# Harvard CS50 2026 Course Notes

This repository contains practice files and course experiments from Harvard CS50 2026.

## Learning Journey

This workspace is organized to show how foundational computer science skills were learned and applied:

- `C/`: Basic C programs with conditionals, loops, and user input.
- `Arrays/`: Array handling, averaging, debugging, and exit status examples in C.
- `memory/`: C examples that explore pointers and string manipulation.
- `Python/`: Python scripts covering input/output, control flow, data structures, file handling, and introductory object-oriented code.
- `FLASK/`: A small web application using Flask routes and templates.
- `Problem_set5/speller/`: A CS50-style spell-checker project using dictionaries and file I/O.
- `WEB/`: Front-end HTML, CSS, and JavaScript examples demonstrating page structure, styling, and browser APIs.

## WEB Exercises

The `WEB/` folder contains foundational front-end exercises in HTML and CSS. These pages demonstrate layout, styling, and basic client-side interaction patterns learned during the course.

- `home.html`: A simple homepage with navigation and content structure.
- `hello.html`: Basic HTML content for greeting display.
- `image.html`: Example of embedding images into a web page.
- `geolocation.html`: Demonstrates browser geolocation access.
- `search.html`: Shows a search form and input handling.
- `table.html`: Uses HTML tables to present structured data.
- `ul.html`: Demonstrates unordered lists and content formatting.
- `JS.html`: Shows how JavaScript can be integrated into a page.
- `realexpressions.html`: Contains regular expression examples and validation concepts.
- `style.css`: Central stylesheet for page design and typography.
