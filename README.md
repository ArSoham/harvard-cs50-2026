# Harvard CS50 – 2026

This repository contains my notes, practice files, problem sets, and experiments from **Harvard University's CS50: Introduction to Computer Science**.

CS50 has honestly been one of the most beneficial courses I've taken so far. It taught me much more than just programming syntax or how to write code. It helped in understanding how computers work, how to approach problems logically, and, most importantly, how to break down complex problems into smaller, manageable ones.

From learning C and understanding memory to exploring Python, SQL, Flask, HTML, CSS, and JavaScript, every part of the course introduced me to something new. Some concepts were challenging, and some problem sets took quite a bit of time to figure out, but that was also what made the learning experience valuable.

I'm keeping this repository as a record of that journey.

## What I Learned

Throughout the course, I explored several areas of computer science:

- **C Programming:** Variables, conditionals, loops, functions, and fundamental programming concepts.
- **Algorithms and Data Structures:** Arrays, searching, sorting, and understanding algorithmic efficiency.
- **Memory:** Pointers, addresses, memory allocation, and string manipulation.
- **Python:** Syntax, control flow, data structures, file handling, and introductory object-oriented programming.
- **SQL:** Working with databases and understanding basic database operations.
- **Web Development:** HTML, CSS, JavaScript, and building interactive web experiences.
- **Flask:** Introduction to backend development through routes, templates, and web applications.
- **Problem Solving:** Learning to think critically, debug systematically, and approach unfamiliar problems.
